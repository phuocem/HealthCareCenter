# HealthX - Hệ thống Quản lý Y tế Toàn diện

HealthX là giải pháp di động hiện đại được thiết kế nhằm tối ưu hóa quy trình quản lý bệnh viện và nâng cao trải nghiệm chăm sóc sức khỏe cho bệnh nhân. Ứng dụng cung cấp một nền tảng kết nối liền mạch giữa bệnh nhân, bác sĩ và đội ngũ quản lý y tế.

## 🚀 Tính năng chính

### 🏥 Dành cho Bệnh nhân
- **Đặt lịch khám thông minh:** Tìm kiếm và đặt lịch với bác sĩ chuyên khoa chỉ trong vài thao tác.
- **Quản lý hồ sơ y tế:** Theo dõi lịch sử khám bệnh, kết quả xét nghiệm và đơn thuốc điện tử.
- **Theo dõi sức khỏe:** Cập nhật các chỉ số sinh tồn và nhận thông báo nhắc lịch.

### 👨‍⚕️ Dành cho Bác sĩ & Nhân viên
- **Quản lý lịch hẹn:** Xem và điều phối danh sách bệnh nhân khám trong ngày.
- **Bệnh án điện tử:** Cập nhật chẩn đoán và chỉ định cận lâm sàng trực tiếp trên hệ thống.
- **Quản lý kho dược:** Theo dõi tồn kho, hạn sử dụng và cấp phát thuốc chính xác.

### 🛡️ Quản trị hệ thống
- **Quản lý nhân sự:** Điều phối đội ngũ bác sĩ, nhân viên và phân quyền hệ thống.
- **Cấu hình dịch vụ:** Quản lý danh mục phòng ban, dịch vụ khám và bảng giá y tế.

## 🛠️ Công nghệ sử dụng

- **Frontend:** Flutter (Dart) - Đảm bảo trải nghiệm mượt mà trên cả Android & iOS.
- **State Management:** GetX - Tối ưu hóa hiệu năng và quản lý luồng dữ liệu.
- **Backend:** Supabase (PostgreSQL) - Hệ thống lưu trữ dữ liệu thời gian thực và bảo mật.
- **Authentication:** Supabase Auth - Quản lý định danh người dùng an toàn.

## 📥 Cài đặt

1. Clone dự án:
   ```bash
   git clone https://github.com/your-repo/HealthCareCenter.git
   ```
2. Cài đặt dependencies:
   ```bash
   flutter pub get
   ```
3. Cấu hình môi trường:
   - Tạo file `.env` từ file mẫu.
   - Thiết lập URL và Key Supabase của bạn.
4. Chạy ứng dụng:
   ```bash
   flutter run
   ```
